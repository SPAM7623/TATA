KEY INSIGHTS & LESSONS LEARNED
================================================================================

1. EDA-Driven Feature Engineering
   → 15 focused features outperform 44 generic features
   → SHAP values guide feature prioritization effectively
   → Visualization analysis essential for domain understanding

2. SMOTE + Probability Calibration Critical
   → Training on balanced data (SMOTE) gives miscalibrated probabilities
   → Must apply calibration for realistic probability estimates
   → Threshold of 0.20-0.25 appropriate, NOT 0.50 (default)

3. Class Imbalance Handling Strategy
   → Simple weighting insufficient (ROC-AUC 0.8678)
   → SMOTE alone too aggressive in precision loss (ROC-AUC 0.9987)
   → Hybrid (weighted + SMOTE) provides best balance (ROC-AUC 0.9988)

4. Feature Selection Impact
   → All features must trace to EDA insights (traceability)
   → Instability features highly predictive for defects
   → Interaction features capture non-linear relationships

5. Cross-Validation Strategy
   → Stratified K-Fold essential for imbalanced data
   → 5-fold provides sufficient variance estimation
   → Nested CV required for threshold optimization
