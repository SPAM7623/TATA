================================================================================
UNDERSTANDING THE PREDICTIONS
================================================================================

Prediction Logic:
  if probability_calibrated >= 0.25:
      prediction = 1 (DEFECT)
  else:
      prediction = 0 (NORMAL)

Why Threshold 0.25?
  - Model trained on SMOTE-balanced data (1:1 defect:normal)
  - But test data has 19.5:1 imbalance (real world ratio)
  - Calibration adjusts probabilities to match real ratio
  - Threshold of 0.25 is optimal for this imbalance
  - Default threshold 0.50 would miss 90% of defects!

Confidence Score:
  - How far is probability from threshold?
  - confidence = |probability - threshold| / max_distance
  - Range: 0 (near threshold) to 1 (far from threshold)
  - Higher = more confident in prediction

Example Interpretations:
  
  Sample 0: prob=0.0290, prediction=0, confidence=0.295
  └─ Very low probability (0.0290 << 0.25)
  └─ Clearly normal with high confidence
  
  Sample 19: prob=0.7541, prediction=1, confidence=0.672
  └─ Very high probability (0.7541 >> 0.25)
  └─ Clearly defect with high confidence
  
  Sample 27: prob=0.2779, prediction=1, confidence=0.037
  └─ Just above threshold (0.2779 ≈ 0.25)
  └─ Borderline defect with low confidence
  └─ Worth manual inspection

TECHNICAL NOTES

Feature Engineering in Phase 5:

The code implements the same 15 engineered features as Phase 4 V2:

PRIORITY 1: X36-Centric (3 features)
  X36/X35 - Cooling parameter ratio (handles division by zero)
  X36/X34 - Alternative cooling ratio
  X36xX41 - Interaction with control parameter

PRIORITY 2: Cooling Cluster (3 features)
  X35/X34 - Within-cluster imbalance (from 259% instability)
  X35xX41 - Secondary danger interaction
  X34-X36 - Difference capture

PRIORITY 3: Top Dangerous Interactions (5 features)
  X29xX41, X30xX41, X31xX41, X32xX41, X13xX41
  (From EDA interaction analysis - risk scores 32-37)

PRIORITY 4: Row Statistics (3 features)
  row_mean - Average across all features (coil signature)
  row_std - Variability (signal consistency)
  instability - Coefficient of Variation (CV)

PRIORITY 5: Rolling Cluster (1 feature)
  rolling_mean - Secondary SHAP drivers (X10, X13, X14, X16)

Model Retraining in Phase 5:

The pipeline retrains the model on FULL training data to maximize
learning from all available data before making test predictions:
  1. Load full training set (1352 samples)
  2. Generate all 15 engineered features
  3. Apply SMOTE for oversampling (2572 samples after)
  4. Train XGBoost with weighted loss
  5. Fit sigmoid calibrator on same training data
  6. Apply to test data for predictions

This ensures:
  ✓ Maximum use of training data
  ✓ Calibration aligns probabilities correctly
  ✓ No data leakage (calibrator not trained on test)
  ✓ Production-ready confidence scores
