PYTHON LIBRARIES USED
================================================================================

Data Processing & Analysis:
  • pandas (v1.x+)
    - CSV file I/O (read_csv, to_csv)
    - DataFrame manipulation (concat, merge, groupby)
    - Data aggregation and statistics
    - Missing value handling

  • numpy (v1.x+)
    - Array operations and computations
    - Statistical functions (mean, std, percentile)
    - Mathematical operations (divide, multiply)
    - Non-finite value handling (np.errstate, np.isfinite)
    - Error handling for numerical edge cases

Visualization:
  • matplotlib (v3.x+)
    - Line plots, scatter plots, histograms
    - Subplots for multi-panel visualizations
    - Heatmaps (with auxiliary colorbar)
    - Saved as PNG files for EDA documentation

  • seaborn (v0.x+)
    - Statistical plots (boxplots, violin plots)
    - Correlation heatmaps with dendrograms
    - Clustermap visualizations
    - Enhanced aesthetics over matplotlib

Machine Learning:
  • scikit-learn (v0.2x+)
    - Cross-validation:
      * StratifiedKFold (maintains class distribution)
      * cross_validate (multiple metrics)

    - Preprocessing:
      * StandardScaler (feature normalization)
      * MinMaxScaler (feature scaling)

    - Metrics:
      * roc_auc_score, f1_score, precision_score, recall_score
      * confusion_matrix, classification_report
      * roc_curve, precision_recall_curve
      * auc (Area Under Curve)

    - Clustering:
      * KMeans (operating regime detection)
      * AgglomerativeClustering (hierarchical)
      * linkage methods (Ward, complete)

    - Anomaly Detection:
      * IsolationForest (outlier detection)

    - Dimensionality Reduction:
      * PCA (Principal Component Analysis)
      * UMAP (Uniform Manifold Approximation)
      * TSNE (t-Distributed Stochastic Neighbor Embedding)

    - Ensemble:
      * RandomForestClassifier (baseline comparison)

  • xgboost (v1.x+)
    - XGBClassifier (gradient boosting model)
    - Hyperparameters tuning
    - Cross-validation integration
    - Feature importance extraction
    - Model serialization (pickle)

  • lightgbm (v3.x+)
    - LGBMClassifier (baseline comparison)
    - Fast gradient boosting
    - Cross-validation integration
    - Feature importance extraction

Class Imbalance Handling:
  • imbalanced-learn (v0.8+)
    - SMOTE (Synthetic Minority Oversampling Technique)
      * Parameters: k_neighbors=3, random_state=42
      * Generates synthetic defect samples
      * Balances class distribution for training

    - BalancedBaggingClassifier
      * Tested as alternative to SMOTE
      * Bootstrap with balanced subsets

Model Interpretation:
  • shap (v0.x+)
    - TreeExplainer for tree-based models
    - SHAP values for feature importance
    - Summary plots (bar chart, dependence plot)
    - Force plots (individual prediction explanations)
    - Used to identify dominant features (X36)

Statistical Analysis:
  • scipy (v1.x+)
    - stats.mannwhitneyu (Mann-Whitney U test)
    - Univariate feature significance testing
    - Tested 39/49 features as significant

Probability Calibration:
  • sklearn.calibration.CalibratedClassifierCV
    - Sigmoid/Platt scaling method
    - Calibrates probabilities on validation folds
    - Ensures realistic confidence scores
    - Critical for threshold optimization

System & File Operations:
  • os, sys
    - File path operations
    - Working directory management
    - Environment variable handling

  • pickle
    - Model serialization and deserialization
    - Saves trained models for deployment
    - Files: model_xgboost.pkl, model_lightgbm.pkl, etc.

Warnings Management:
  • warnings
    - Filter out non-critical warnings
    - Cleaner console output

5. src/phase_4_feature_engineering_v2_fixed.py (425 lines) [V2 FIXED - FINAL]
   Purpose: EDA/SHAP-guided feature engineering WITH probability calibration

   Key Components:
     • ImprovedFeatureEngineeringPipelineFixed class
       - Same 15 engineered features as V2
       - SMOTE for imbalance handling
       - SIGMOID CALIBRATION for probability alignment

     • Key Fix:
       - CalibratedClassifierCV with method='sigmoid'
       - Applied on validation folds
       - Adjusted threshold from 0.56 to 0.17
       - Aligns probabilities with 19.5:1 class ratio

     • Process:
       1. Train model on SMOTE-balanced data
       2. Get raw probabilities on validation fold
       3. Fit sigmoid function to calibrate
       4. Find optimal threshold on calibrated probabilities
       5. Results: threshold 0.17, F1 0.3316, recall 0.4697

   Advantage over V2:
     - Realistic probability estimates
     - Correct threshold for production
     - Proper handling of class imbalance calibration

   Output Files:
     - phase4_v2_fixed_engineered_features.csv

DEPLOYMENT & REPRODUCIBILITY
================================================================================

To Reproduce Results:

1. Data Preparation:
   $ python src/alpha_defect_complete.py
   → Generates train_cleaned.csv, test_cleaned.csv, and EDA outputs

2. Baseline Models:
   $ python src/phase_3_baseline_models.py
   → Trains 3 baseline models, exports model_comparison.csv

3. Feature Engineering & Final Model (FIXED VERSION):
   $ python src/phase_4_feature_engineering_v2_fixed.py
   → Trains final model with calibration, exports metrics

4. Test Predictions:
   $ python src/phase_5_test_predictions.py
   → Generates test_predictions_simple.csv, test_predictions_final.csv

Required Python Environment:
  • Python 3.7+
  • pandas, numpy, scipy, scikit-learn, xgboost, lightgbm
  • imbalanced-learn, shap, matplotlib, seaborn
  • All specified with exact version compatibility

Reproducibility Notes:
  • All random_state parameters fixed (42) for consistency
  • Stratified K-fold ensures class distribution preservation
  • No random transformations beyond specified SMOTE
  • Seeds control numpy, sklearn, xgboost randomness
